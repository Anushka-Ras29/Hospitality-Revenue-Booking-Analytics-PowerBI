# Hospitality Revenue & Booking Analytics | Power BI

## 📊 Project Overview

This project focuses on analyzing hospitality booking data using Microsoft Power BI to evaluate revenue performance, occupancy, pricing, booking platforms, and property-level performance.

The dashboard transforms raw booking data into interactive KPIs and visual insights to support business performance analysis.

---

## 🎯 Business Objectives

- Analyze overall revenue and RevPAR performance
- Monitor occupancy and ADR trends
- Evaluate Week-over-Week (WoW) performance
- Compare occupancy across room categories
- Analyze booking platform performance
- Identify top-performing properties by revenue
- Monitor cancellation and realization metrics
- Provide actionable business insights through an interactive dashboard

---

## 🛠️ Tools & Technologies

- Power BI
- DAX
- Power Query
- Data Modeling
- Data Cleaning
- Data Visualization
- KPI Analysis
- Time-Series Analysis
- WoW Analysis

---

## 📌 Key KPIs

| KPI | Description |
|---|---|
| Revenue | Total realized revenue |
| RevPAR | Revenue per available room |
| Occupancy % | Percentage of available capacity utilized |
| ADR | Average Daily Rate |
| Realisation % | Percentage of bookings realized after cancellations and no-shows |
| Cancellation % | Percentage of bookings cancelled |

---

## 📈 Dashboard Analysis

### Revenue & Booking Performance

The dashboard tracks revenue performance and booking trends across different weeks, cities, room classes, booking platforms, and properties.

### Pricing & Room Performance

ADR and RevPAR are analyzed to understand pricing performance and revenue generated from available room capacity.

### Occupancy Analysis

Occupancy is analyzed by week and room category to identify changes in room utilization.

### Booking Platform Analysis

Realisation % and ADR are compared across booking platforms to evaluate platform-level performance.

### Property Performance

Properties are ranked based on revenue contribution to identify high-performing properties.

---

## 🔍 Key Insights

- Revenue performance varies significantly across weeks and selected business segments.
- RevPAR and ADR trends help evaluate room revenue and pricing efficiency.
- Occupancy differs across room categories.
- Booking platforms show differences in realization and ADR performance.
- Property-level analysis helps identify high-revenue properties.
